# PLC 架构交互页面

根路径 `/` 直接显示 PLC 架构交互文档，不使用入口门户或 iframe。`/plc-architecture/` 保留为同一文档的兼容地址。

原能力图谱及详情保留在 `/capability-map/`，不从新首页提供入口，并添加 noindex。原有晶圆电镀、三维拉弯机及机器人独立页面继续保留。旧图谱的源程序保留，可按需恢复。

首页保留原站的 ICP、公安备案链接和公安图标；离线导出时移除这些宿主页面元素。

## 内容与功能

- 架构总览：24 个节点及可编辑的程序说明。
- 单片执行流程：W01 从晶圆盒经候选 PLT、SRD 返回原盒原槽，11 步详情按需展开。
- Unit ↔ Module：任务、配方、能力与占用、设备状态、任务结果、机器人交接。
- 操作流程：手动单点、手动简单程序、自动程序及各自报警分支。
- 保留本机草稿、章节编辑、参考初稿、JSON 导入导出及独立 HTML 导出。

这是架构说明和教学示例，不连接 PLC、ADS 或机器人，不表示六腔整机程序已实现或联调。

## 更新方式

1. 在原“PLC架构交互说明”源目录完成编辑，运行该目录的 `node build-web.cjs`，得到独立的 `PLC程序架构说明.html`。浏览器改文需先导出，不会自动写回源文件。
2. 在本仓库运行：

   ```text
   node scripts/prepare-plc-architecture.mjs <独立HTML文件的路径>
   ```

3. 检查生成的根目录 `index.html` 和 `public/plc-architecture/index.html`，执行仓库检查与构建后按现有 ESA 发布渠道部署。`vite.config.ts` 同时保留隐藏图谱和机器人页面的构建入口。

打包保留全部原始说明数据，添加源文件 SHA256 标识并适配离线导出。首页只显示框架文档；兼容地址提供返回首页链接。发布构建仍使用现有访问门禁插件，未修改网关、域名、鉴权或源站规则。导出的离线 HTML 会移除宿主导航、发布标识、站点门禁/ESA 会话桥接脚本，以及宿主注入的显示锁和 base，保留当前编辑内容。

不把 PLC 工程、内部交接文档、开发源码或本地备份打包到该公开资源目录。
