# PLC 架构交互页面

网站根路径与 `/#/capabilities` 显示工业自动化能力图谱首页，顶部导航与完整页脚在所有页面统一显示，备案信息保留。`/capability-map/` 作为独立入口继续可用；PLC 程序架构位于 `/#/plc`，其余能力页面沿用相同导航。

PLC 栏目包含架构总览、单片执行流程、Unit ↔ Module 交互、操作流程、框架细化和 PackML 状态机。PackML 提供中英双语状态与命令、筛选、放大、复制和图表下载。原 TwinCAT 官方案例可从 PLC 栏目底部打开。

旧 `/plc-architecture/?view=…` 和 `/packml/` 地址会进入 PLC 的对应视图。旧 `/capability-map/` 能力图谱及其栏目地址继续可用。各入口沿用站点访问门禁。

架构说明的数据和交互位于 `src/plc/`。访客默认阅读仓库发布的版本，不读取或删除浏览器草稿。维护说明时访问 `/#/plc?edit=1`，该模式继续读取既有浏览器草稿；修改后按 Ctrl+S 保存到当前浏览器。切换 PLC 视图会保留维护模式。维护模式只是界面切换，不是访问权限控制；浏览器编辑与仓库源码分别保存。

修改站点内容后运行 `npm run build`，按现有 ESA 发布渠道部署。
