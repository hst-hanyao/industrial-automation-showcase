# PLC 架构交互页面

根路径 `/` 直接显示 PLC 架构交互文档，不使用入口门户或 iframe。`/plc-architecture/` 保留为同一文档的兼容地址。

全站导航保留上位机、PLC、运动控制、机器视觉和“3D 演示”的原有顺序。“3D 演示”包含晶圆电镀工艺和三维拉弯机。网站默认进入 PLC 架构总览，PLC 页头显示全站导航和各视图入口。

能力图谱及详情保留在 `/capability-map/`，架构首页和 PackML 页均不提供图谱入口。图谱保留 `noindex`，其 PLC 卡片和导航进入完整架构文档 `/plc-architecture/`，原 TwinCAT 案例通过 `/capability-map/#/plc` 兼容访问。

首页保留原站的 ICP、公安备案链接和公安图标；离线导出时移除这些宿主页面元素。

## 内容与功能

- 架构总览：24 个节点及可编辑的程序说明。
- 单片执行流程：W01 从晶圆盒经候选 PLT、SRD 返回原盒原槽，11 步详情按需展开。
- Unit ↔ Module：任务、配方、能力与占用、设备状态、任务结果、机器人交接。
- 操作流程：手动单点、手动简单程序、自动程序及各自报警分支。
- 框架细化：Module 总入口、Unit 扫描时序、数据归属、任务与搬运状态、跨任务交接五个主题。
- PackML 状态机：与上述视图同级的独立页面 `/packml/`，共用「PLC 程序架构」页头、视图导航和基础样式。包含自动生产模式的中英双语状态流转、17 个状态、11 个命令以及可筛选、放大和下载的图表。正文位于 `public/packml/index.html`，沿用站点门禁。
- 保留右侧节点说明编辑、参考初稿与 Ctrl+S 本机草稿保存。页头英文标语、副标题、全局工具及草稿状态区按要求移除。

这是架构说明和教学示例，不连接 PLC、ADS 或机器人，不表示六腔整机程序已实现或联调。

## 更新方式

1. 使用包含“框架细化”的新版 `plc-framework-preview/PLC程序架构说明.html`。在该预览源目录维护内容后运行 `node build-web.cjs`，生成独立 HTML。避免再次使用只有四个视图的旧目录版本。浏览器草稿不会自动写回源文件。
2. 在本仓库运行：

   ```text
   node scripts/prepare-plc-architecture.mjs <独立HTML文件的路径>
   ```

3. 检查生成的根目录 `index.html`、`public/plc-architecture/index.html` 和 `public/packml/index.html` 的共用页头，执行仓库检查与构建后按现有 ESA 发布渠道部署。`vite.config.ts` 同时保留隐藏图谱和机器人页面的构建入口。

打包保留全部原始说明数据，添加源文件 SHA256 标识，移除选定的页头内容，并保留原有离线导出函数的宿主适配。首页与兼容地址均显示五个内嵌视图和独立的 PackML 页面入口。发布构建仍使用现有访问门禁插件，未修改网关、域名、鉴权或源站规则。右侧编辑后可用 Ctrl+S 保存到本机浏览器；网页不再提供全局导入导出按钮。

不把 PLC 工程、内部交接文档、开发源码或本地备份打包到该公开资源目录。
