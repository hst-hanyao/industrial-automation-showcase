# 晶圆电镀工艺 3D 教学演示与工业自动化能力图谱

网站首页为工业自动化能力图谱，使用 Vite / React / TypeScript，包含首页及上位机、PLC、运动控制、机器视觉四个详情页。页头的教学链接进入 `/waferplt/`，在同一个工作区观察晶圆电镀工艺和前后手臂。

## 密码入口

打开网站首先显示访问密码页，验证后返回原来请求的页面，包括哈希路由和三维教学子页。验证状态只保存在当前标签页的会话存储中，8 小时后需要重新输入；密码错误时不会进入正文。浏览器需允许 JavaScript 和会话存储，密码校验通过 HTTPS 或本机 localhost 预览运行。

`public/site-access/` 提供统一密码页及验证脚本；`scripts/site-access.ts` 在开发服务和生产构建中为全部 HTML 入口加门禁，避免只保护 React 首页而遗漏独立子页。页面在脚本加载前默认隐藏，验证通过后才显示。生产构建会检查全部入口的门禁标记，并按最终带门禁的 HTML 更新教学资源清单。

这是静态网站的前端展示门禁，可被技术手段绕过，不是服务器访问认证；公开仓库源码和静态资源仍可直接获取。需要保护保密资料时，应使用服务器或托管平台的身份认证。

## 统一教学工作区

`/waferplt/` 将整机、APT 预湿、PLT 电镀、SRD 清洗甩干及前后手臂教学放在一起。右侧按两列组织按钮：第一列选择模块结构，第二列选择工艺流程。进入页面、切换模块或选择步骤时保持暂停；点击“执行本步”只运行当前步骤，到步骤边界后停止，由讲解者继续控制。

结构视图按选择筛选标签；搬运流程标明当前动作的起点、机械手叉和目标，状态条同步显示晶圆干湿分类及实际承托。每个流程独立保存动作与进度，查看结构或刷新当前标签页后可暂停恢复；TSV／WLP 分开记忆，重置仅影响当前流程。记录使用当前标签页的会话存储，不跨设备同步。

整机总览、FOUP、前手臂、后手臂和搬运流程共用整机总览的三维场景、机构及工位布局。选择手臂时，相机在该场景中平滑移动到对应区域；FOUP、定向和交接位置以及 APT／PLT／SRD 工位保持原有空间关系。旧的独立直线搬运场景退出教学入口。模块近景及其他观察视角也采用平滑相机过渡；视角切换本身不会启动工艺动作。

前手臂负责 FOUP、定向与干片交接；后手臂通过独立的干／湿末端连接 APT、PLT、SRD。SRD 干燥完成后才由干片末端接回晶圆。旧 `/waferplt/robots/` 地址继续可用，并回到统一教学入口；旧 `/waferplt/modules/` 地址进入统一工作区的 APT 结构视图。

网站使用交互模型，视频仅在本地保存。五份原视频及原视频记录已备份到本项目的 `local-backups/20261016-teaching-videos/`，其中 `manifest.json` 记录相对原路径、文件大小和逐文件 SHA-256 校验值。五份视频共 49,345,310 字节，均在源与备份校验一致后移出 `public`。`local-backups/` 已加入 Git 忽略规则，不参与构建和 Pages 发布。

结构采用公开资料的独立教学重建。300 mm 晶圆及法拉第公式用于定量锚点，其余几何、材料外观、运动轨迹、阶段时长和工艺参数均为教学设定。动画、运动学及互锁展示不代表真实设备控制、制造 CAD、工艺配方或现场验收。

## 三维拉弯机

页头「3D 演示」菜单可选择「晶圆电镀工艺」或「三维拉弯机」。拉弯机子页面位于 `/stretch-bender/`，按提供的设备图片近似重建；图片姿态为全部十六轴的零位。左右各八轴可用数值与滑块独立设置，单轴、单侧与整机归零，以及完整姿态 JSON 保存和载入均在页面内完成。

每侧的运动带动顺序为：床身 → 下层滑台 → 拉弯回转座 → 上层滑台 → 白色立架 → Z 升降 → 摆臂旋转 → 引申旋转 → 引申滑块 → 夹头旋转。回转中心随下层平移，不受上层位移影响；拉弯只带动上层及其机构旋转，下层不转。按实机照片重建内侧白色回转座、长转臂和两个水平回折拖链；回转中心距立架的内移量暂按比例估算为 650 mm，立架及夹头的图示零位保持。单动引申时导轨、电机不动。尺寸、滑块显示范围为估算；正负方向采用页面说明的坐标约定，尚未代替实机行程、限位与控制参数。源码和使用说明见 `src/stretch-bender/README.md`。

`npm run build:stretch-bender` 生成可直接打开的 `public/stretch-bender/index.html`，内联 Three.js、运行代码与样式，无运行时 CDN 依赖；参考图片及其查看入口已移除，生成页面不包含参考图片。`npm run dev` 的准备步骤与正式构建自动生成该页面。开发和预览服务均支持子页面目录入口。

## 开发与验证

```sh
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run build
```

生产输出为 `dist`。构建前后通过 `scripts/check-teaching-publication.mjs` 检查发布资源，拒绝视频文件、播放器、视频链接、本地备份目录及已移除的展示文字。准备阶段刷新 `public/waferplt/publication.json` 的静态文件清单；构建后核对相应输出文件的大小和 SHA-256。检查结果以当前命令输出为准，不沿用历史测试数量。

统一入口及流程选择在 `public/waferplt/teaching-workbench.js`；整机几何与布局来自 `public/waferplt/machine/electroplating-machine.html`，教学适配器在同目录树的 `shared/` 下管理单步控制、搬运状态和相机过渡。旧机器人 URL 仅用于兼容跳转。预构建工艺模块也位于 `public/waferplt/`，Three.js 固定为 0.170.0。运行素材随构建提供，无后端接口或外部 CDN 依赖。

几何与交互验收需要同时核对：切换整机和手臂时保持同一场景及工位对象；任一时刻只有一片被跟踪晶圆及唯一归属；湿片由湿末端在湿工艺区流转，SRD 干燥完成才转为干片；相机从当前姿态连续过渡，快速改选视角也保持连续。旧独立场景的坐标及测试结果不能代替这些检查。
