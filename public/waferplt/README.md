# 晶圆电镀工艺 3D 教学工作区

[进入统一教学演示](index.html) · [返回网站首页](../)

整机、前后手臂及 APT／PLT／SRD 工艺在同一个教学入口中观察。右侧第一列用于选择模块结构，第二列用于选择工艺流程。页面默认暂停；选择模块或步骤后也保持暂停，点击“执行本步”只执行所选步骤，到步骤边界后停止。

整机总览显示全部主要模块标签，选择某个模块结构后仅保留对应标签。搬运流程按当前动作标出起点、参与的实际机械手叉及目标工位，并突出当前承托。状态条显示晶圆干湿状态、实际承托和本步目标；交接中点改变承托，APT 预湿及 SRD 甩干完成后才改变干湿分类。独立模块状态只描述该模块内部可见的交接托叉和承托机构。

各流程分别记住动作和进度；查看结构、切换流程或刷新当前标签页后，返回时恢复并保持暂停。TSV 与 WLP 分开保存，WLP 铜柱／RDL 记住最后选择的子步骤。“重置本流程”仅重置当前流程。进度保存在当前浏览器标签页的会话存储中；存储不可用时仍保留页面内存中的进度，不跨设备同步。

整机总览与前后手臂使用同一三维场景、同一套机构和工位布局。FOUP、定向、交接以及 APT／PLT／SRD 的位置保持整机总览中的空间关系；观察手臂时，相机平滑移到该区域。模块近景和其他观察视角也以平滑相机过渡连接，切换视角不启动工艺。

| 模块 | 结构观察重点 | 工艺观察重点 |
| --- | --- | --- |
| 整机 | FOUP、交接位、各工位与机器人之间的位置 | 从装片到回片的路线 |
| 前后手臂 | 整机中原有手臂、干湿专用末端与交接位 | 在整机布局内取片、定向、交接、湿片流转与干片回收 |
| APT 预湿 | 侧门、支撑、喷嘴、排液与气路 | 装片、密封抽气、润湿、复压和湿片交接 |
| PLT 电镀 | 夹持头、密封、电触点、CIRP、膜与阳极 | 接片、密封、浸润、通电、断电提头和出片 |
| SRD 清洗甩干 | 边缘夹爪、双面喷淋、主轴与承液碗 | 夹持、漂洗、停水、甩干、停转和取片 |
