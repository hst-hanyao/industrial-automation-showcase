# SRD 清洗／旋转干燥：结构证据与动画约束

核查日期：2026-10-15。范围：供本地 SABRE 3D 教学项目使用的单晶圆 SRD 结构研究。这里把“直接公开的结构”“普通 SRD 工序”和“本项目的教学选择”分开记录。公开专利不能证明某台商业 SABRE 3D 的完整实装配置。

## 结论与采用方案

本轮默认 SRD 演示采用 **边缘夹持 → 晶圆旋转并用 DIW 漂洗正背面 → 停水、旋转排液 → 继续甩干 → 减速停转、松夹取片**。承液碗、挡液唇、下部排液以及边缘夹爪应真实可见。上方喷淋与下方喷嘴为独立液路；下方喷嘴不能被不透水的实心托盘挡住。此顺序与 Lam 的普通 SRD 背景说明相符；夹爪采用其另一公开实施例的翻转机构，属于明确标注的教学组合。[US6578853B1，Background 和 FIG.2A／2B、8A／8B](https://patents.google.com/patent/US6578853B1/en)。

Lam 当前 SABRE 3D 产品页只公开“可配置的多电镀及前后处理单元”，未给 SRD 内部总装、精确尺寸、气体配方或喷嘴数量。因此本项目可以说明其工艺位置，不能把下面的通用 SRD 组合冠名为商业机原装剖面。[Lam SABRE 3D 产品页](https://www.lamresearch.com/product/sabre-3d/)。

## 结构 → 工序 → 动画映射

下列模型的唯一固定物理规格为 **300 mm 晶圆直径**。碗体、卡盘、法兰、喷嘴及支架尺寸、材质外观与喷淋流量均为教学重建参数；专利示意图不能量取制造尺寸。背面板间隙在模型中放大到约20 mm便于观看，不能读取为专利或商业机制造间隙。动画转速和播放周期也不能作为量产 recipe。

| 可视化部件 | 为什么需要它 | 对应工序／动画行为 |
| --- | --- | --- |
| 底座、脚垫、立腿、承台 | 碗和电机需要有真实承重路径 | 静态支撑，不随卡盘转动 |
| 厚壁承液碗、挡液唇、环形收液空间 | 接收离心甩出的液体，限制飞溅 | 外壳可半剖／透视；液体从晶圆边缘落入碗内，再汇向低位排液口 |
| 排液口、排液软管、阀／接头 | 废液必须离开腔体 | 漂洗时出现明确的去向；停水后仍有短暂排液，甩干结束后流线消失 |
| 下部电机、主轴、轴承／密封座 | 提供同轴转动并隔开湿区与传动 | 主轴和卡盘同速；固定轴承座、电机外壳和供液管不转 |
| 卡盘、背面板和晶圆间隙 | 支承晶圆并保留背面流体通道 | 与晶圆同转；背面板不穿过晶圆；解剖视图让两者间隙可见 |
| 三处边缘夹爪、转轴、连杆和中心楔块 | 说明晶圆为何能在旋转时保持位置 | 装卸时停转并开夹；夹紧后才转动。分解观察中显示楔块升降与夹爪翻转的联系；零速取片 |
| 300 mm 晶圆、镀铜图形薄层 | 连接 PLT 的输出与 SRD 的清洗任务 | 表面铜量保持不变，残留液膜定性减少；不展示铜柱被纯 DIW 化学溶解 |
| 上方 DIW 喷臂／喷嘴、供水管、阀 | 正面漂洗 | 停转或低速装片后开启水流，在旋转时铺展；停水后喷流立即关闭 |
| 下方独立喷嘴及供液路 | 背面漂洗而非只洗正面 | 喷嘴出口位于晶圆与背面板间的可达区；水流到背面后向外径向排出 |
| 晶圆边缘向外的液片／少量液滴 | 让离心排液被读懂 | 仅作定性示踪，不冒充 CFD、颗粒洁净度或精确液膜厚度；甩干阶段逐渐减弱 |
| 洁净气流接口（可选，默认关闭） | 解释另一公开 SRD 方案的空气管理 | 使用时明确写“过滤洁净空气方案”；本轮不把它改称 N₂，不加入 IPA／Marangoni 流线 |

以上映射由前述资料组合成教学机构：夹爪开闭遵循 US6578853B1；背面通路参考 US6497241B1；喷淋与收液的空间关系参考 US8261758B2。它们不证明实际商用机将这些构件装在同一腔中。

## 普通 SRD 的阶段状态

| 阶段 | 机械状态 | 流体状态 | 对观众说明 |
| --- | --- | --- | --- |
| 01 湿片就位 | 主轴停转，夹爪打开；晶圆由转移端送到支承点 | DIW关闭 | “电镀后仍有残留液，需要漂洗” |
| 02 边缘锁定 | 夹爪闭合，夹住外缘；喷嘴处于工作位置 | DIW尚未打开 | “夹稳后才能旋转” |
| 03 正背面 DIW 漂洗 | 卡盘与晶圆旋转；夹爪保持闭合 | 上下喷嘴开启；水从中心／喷淋区域向外铺展，废液入碗并排出 | “用新鲜 DIW 置换残留电镀液” |
| 04 停水排液 | 转动继续，喷嘴退出或停止供水 | 阀关闭；晶圆上的水被甩向外围，排液继续 | “先停水，继续旋转带走液体” |
| 05 旋转干燥 | 继续转动，教学示意可提高转速 | 不再给水；残留液示踪减少 | “甩干画面不代表在线测得干燥终点” |
| 06 减速取片 | 先减速到停转，再开夹；机器人取片 | 无喷淋和持续液滴 | “干片离开 SRD，返回后续流转” |

阶段拆分、时长及转速倍率是教学叙事选择。US6578853B1 支持“供DIW后停水、继续高速旋转”的基本次序；它没有给本项目所用的精确分段秒数。旋转角度可按 θ=∫ωdt、ω=2πn/60 计算，但只有标成示例设定的 n，不能把可计算的动画角速度称为实机测量。纯 DIW SRD 不新增电荷、不新增铜；PLT 的沉积累计在 SRD 全程保持不变。

## 本轮不应混入的流程与未核实项

- **EBR／BSE／酸洗**：普通 SRD 只展示漂洗和干燥。若未来加入去边、背蚀、去氧化层，应独立成工艺选项，增加液体来源、废液管理及专门的专利依据，不用纯 DIW 流线代替蚀刻剂。
- **IPA／Marangoni**：US8261758B2 的蒸汽使液体表面张力变化，并不等于“用 N₂吹干”。只有明确选择该特殊方案并写清材料与次序时才绘制。
- **无晶圆清腔**：APT 防污染专利里的清腔循环不属于正常 SRD 晶圆流程。
- **商业 SABRE 3D 的实装**：本轮未取得商用 SRD 总装图、BOM、尺寸、喷嘴分布、晶圆正反朝向转换机构、实机转速曲线、N₂流量或最终干燥判定。站间如需翻片，应明确标注“朝向示意”，不能让晶圆在镜头切换间无解释地反面。
- **流体／洁净验收**：未运行 CFD、旋转件强度或偏心分析；未验证水痕、残铜、离子污染、颗粒、干燥时间、设备产能及真实湿片搬运。

## 制作与复核清单

1. 先观察组装视图，再半剖看碗、背面板间隙、主轴和排液；分解视图只用于解释构造，运行时禁止分解导致液路悬空。
2. 动画至少覆盖装片、夹紧、双面漂洗、停水排液、旋转干燥、停转松夹；暂停冻结主轴、喷淋示踪和阶段时间。
3. 漂洗阶段必须看见液体来自喷口并最终进入碗和排液管；不可从实体托盘中穿出。
4. 所有旋转属于同一个卡盘坐标组；固定喷臂／管道不跟着转；无夹紧时禁止进入旋转阶段。
5. 镀铜表面随晶圆一起转，SRD全程保持PLT铜量。干燥完成为动画设定状态，不声称传感器确认。
6. 画面说明保留“公开专利教学重建”；未以实机资料核实的数值写“示意／示例”。
