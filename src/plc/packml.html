读图要点 How to read

  • Wait State（黄）：稳态，必须收到命令才离开；Acting State（绿）：瞬态，以 -ing 结尾，动作完成后经 SC (State Complete) 自动转移。
  • Execute（蓝）：唯一产生价值的生产状态，是 OEE 计算中唯一计入的产出时间。
  • Hold vs Suspend：Hold 由操作员 / 设备内部触发，需 Unhold 恢复；Suspend 由上下游等外部条件触发，需 Unsuspend 恢复。
  • Stop / Abort 可从任意状态触发，Abort 优先级最高：Abort → Aborting → Aborted → Clear → Clearing → Stopped。
  • 平台无关 / Vendor-neutral：状态编号 1–17 是标准枚举，并非某厂商私有编码；各平台的函数块、枚举类型与命名可以不同，本页只使用标准状态名与命令名。
  • 分层与裁剪 / Layering：可作为 Unit / Module 分层框架的外层状态机；Execute 内部再展开工艺步骤，Stopping 内执行清理流程，并按 UnitMode 选用状态子集。

适用范围 How to apply

  • 平台：IEC 61131-3 PLC、OPC UA / PackTags、上位机 SCADA 或自研控制器均可参照；状态与命令语义一致，实现方式（CASE、函数块、枚举）自行定义。
  • 分层：Unit（整机）负责统一状态与命令下发，Module（腔室 / 单元）各自持有状态机实例；外部请求经模块命令接口转入内部脉冲，状态再统一对外发布。
  • 工艺：Execute 内按工艺步骤推进，Stopping 内执行清理与安全收尾；「正常完成 / 清理完成 / 程序停止 / 有料在制」等工况宜用独立状态表达，避免混用。
  • 裁剪：Production / Maintenance / Manual 等 UnitMode 可只实现状态子集；Hold、Suspend、Complete 等分支按设备实际取舍。
  • 数据：Execute 是唯一产出状态；Wait / Acting / Stop / Abort 的时长可直接用于 OEE 计算与 MES 状态采集。
