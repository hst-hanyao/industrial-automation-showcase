# 三维拉弯机 · 十六轴位置工作台

入口为 `/stretch-bender/`，与 `/waferplt/` 并列。原网站页头的 3D 演示菜单可选择设备。源码经 `npm run build:stretch-bender` 生成 `public/stretch-bender/index.html`；正式构建自动执行此步骤。HTML 内联运行代码、Three.js、样式和用户提供的零位参考图，运行时无需 CDN，可直接打开文件或通过当前 Vite 网站访问。

## 位置与零位

用户参考图的姿态定义为全部十六轴的 `0`。几何保留初始安装角度和位置，轴值作为相对于零位的偏移。左右各八轴，分别保存状态；选择另一侧不会复制、镜像或覆盖轴值。

| 轴 | 运动与带动关系 |
|---|---|
| 下层滑台 | 沿床身 X 方向平移，携带弯曲回转座、上层及整套机构；因此回转中心随下层移动。带编码器异步电机。 |
| 上层滑台 | 安装在拉弯回转座上，沿回转座局部 X 方向平移，携带整套立架；方向随拉弯回转。带编码器异步电机。 |
| 拉弯 | 安装在下层滑台上，在 XY 平面内绕竖直轴线转动，只携带上层滑台、立架及全部架上机构，下层不随它旋转。上层滑台移动不改变回转中心。回转座位于白色立架内侧的长转臂端部，对应实机照片红框下方。 |
| Z | 升降座及架上作业机构上下移动；白色立架本体不参与此轴升降。 |
| 摆臂旋转 | 绕局部 Y 轴，在自身 XZ 平面内转动，携带引申旋转、引申及夹头机构。 |
| 引申旋转 | 绕局部 Z 轴，在随摆臂改变姿态的局部 XY 平面转动。 |
| 引申 | 滑块与夹头沿局部导轨直线运动，单动时导轨、电机保持不动。 |
| 夹头旋转 | 夹头在自身 YZ 平面自转，轴线沿局部 X。与原描述“夹盘旋转”对应。 |

承载顺序为：床身 → 下层滑台 → 拉弯回转座 → 上层滑台 → 白色立架 → Z 升降 → 摆臂旋转 → 引申旋转 → 引申滑块 → 夹头旋转。下层沿床身世界 +X 移动；上层沿回转座局部 +X 移动，零位时与床身 +X 一致，拉弯后方向随之改变。右侧立架在上层滑台之后初始绕 Z 旋转 180° 朝向中央。其余轴采用父机构的局部坐标；正转按右手规则。左右结构对称，不意味着同号值必定产生镜像姿态。

按用户提供的实机视频截图，拉弯回转座位于立架内侧，不是紧贴立架底部；向内的估算偏移改为 `DIMENSIONS.bendPivotInsetX = 0.65 m`，左右镜像。此值由照片比例估算，并非实测尺寸。上层滑台零位含反向安装偏移补偿，因此白色立架、引申导轨与夹头的图示零位世界坐标保持不变。回转中心和固定电机都随下层滑台平移，上层位移和拉弯转角不移动其中心。照片绿框对应两个水平回折坦克拖链，按链节和销盖重建；它们属于线缆导向结构，不作为运动轴或风琴罩。

外部值单位为毫米及角度，内部几何使用米及弧度。毫米比例、零位结构尺寸和滑块显示范围均为按图估算，集中在 `kinematics.ts` 的 `DIMENSIONS` 与 `AXES`；数值输入不会被滑块的展示范围裁剪。默认范围不是实机行程或机械限位。模型不计算碰撞互锁、拉力、塑性成形或回弹。

## 控制

- 左右选项卡各提供八组数值输入、滑块和单轴归零；左／右方向键可切换选项卡。
- 单侧归零保留另一侧；整机归零精确恢复图片姿态。
- 参考、正视、俯视、左侧和右侧视角只改变相机。可拖动旋转、滚轮缩放、右键平移。
- 部件标签与选中轴的局部三轴跟随机构；点击三维部件可选择所属轴。
- 参考图片面板同时保留初始零位图和带红绿框的实机结构照片，便于核对回转座及拖链。
- “保存 / 载入姿态”将全部十六轴导出为版本 1 JSON。导入首先验证左右完整数值和单位，失败保留原姿态。也可在面板内编辑 JSON 再载入。

## 文件与验证

- `geometry.ts`：实体、材料、两个镜像机构、风琴罩、拖链和软管。
- `kinematics.ts`：纯状态验证与正运动学；`kinematics.test.ts` 对解析变换、局部旋转、级联带动、导轨静止及十六轴独立性作测试。
- `studio.ts`：参考 machine skill 的程序化摄影棚、相机与软阴影。
- `main.ts`、`style.css`、`page.html`：工作台交互及单页源。
- `scripts/build-stretch-bender.mjs`：本地依赖打包并内联生成子页面。

```sh
npm run build:stretch-bender
npm run typecheck
npm run lint
npm test
npm run build
npm run dev
```

模型采用 machine skill 的三维实体及材质、灯光方法，并应用 anatomy 的层次、支承、连接细节规范。用户指定的图像还原、十六轴控制优先于技能模板的单滑块及默认故事。模型依据已确认运动关系建立，内部传动、支座精确尺寸和背面细节为推定。第三方许可证见同目录 `THIRD-PARTY-NOTICES.txt`，也内联保留在生成 HTML 中。
